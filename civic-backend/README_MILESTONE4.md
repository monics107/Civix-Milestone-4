# CIVIX Milestone 4 Backend

Implemented:
- Citizen registration/login without Super Admin approval.
- Official registration creates a pending, unverified Official.
- Super Admin verification and activation/deactivation.
- Department assignment controlled by Super Admin.
- Backend department isolation for petitions and polls.
- Petition action plan, rejection reason/solution, work progress and timeline.
- Petition completion -> citizen review -> 75% positive closure rule.
- Duplicate signature/vote protection and closed-petition signing protection.
- Citizen/Official password and profile APIs.
- Monthly reports with PDF and Excel export.
- Super Admin dashboard APIs for Official verification/access.
